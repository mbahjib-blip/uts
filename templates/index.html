Klasifikasi Diabetes dengan Decision Tree

Sumber & Karakteristik Dataset

Dataset Diabetes (Pima Indians) dari Kaggle (asal: National Institute of Diabetes and Digestive and Kidney Diseases, tersedia di UCI Machine Learning Repository). Berisi data pasien perempuan keturunan Pima, usia ≥ 21 tahun.

  • Jumlah baris awal: {{ M.info.baris_awal }}, 8 fitur numerik + 1 target (Outcome: 1 = diabetes, 0 = tidak)
  • Baris duplikat: {{ M.info.duplikat }} → setelah dihapus tersisa {{ M.info.baris_bersih }} baris ({{ M.info.kelas['0'] }} tidak diabetes, {{ M.info.kelas['1'] }} diabetes)

Preprocessing

  1. Menghapus kolom kosong tambahan hasil pemisah ";" pada CSV.
  2. Menghapus data duplikat. Tanpa langkah ini, baris yang sama muncul di data latih dan uji sehingga akurasi menggembung (data leakage). Perbandingan hasil ada di halaman Evaluasi.
  3. Nilai 0 yang mustahil secara medis pada Glucose, BloodPressure, SkinThickness, Insulin, BMI dianggap missing, lalu diisi median:
